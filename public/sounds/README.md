# Ήχοι

- `ruru` (Ruru, προεπιλογή): Move, Capture, Mate = ηχογραφήσεις ξύλινης σκακιέρας του δημιουργού του Ruru
  (27/11/2026), κομμένες και με ήπια ισοστάθμιση· μέρος του Ruru, με την ίδια άδεια (GPLv3). GenericNotify = το ίδιο
  αρχείο με το `wood` (CC0).
- `wood` (Ξύλο): Move = «Piece Placement» (546119), Capture = «Piece Capture» (546120),
  GenericNotify = «Board Start» (546121), από το πακέτο «Chess Puzzle Blitz SFX» του
  [el_boss](https://freesound.org/people/el_boss/packs/30764/) στο Freesound, **CC0 1.0** (κοινό κτήμα).
- `piano`, `nes` (Move, Capture, Check, GenericNotify): του [Enigmahack](https://github.com/Enigmahack),
  **AGPL-3.0-or-later**, από το αποθετήριο [lila](https://github.com/lichess-org/lila) (`public/sound/<σετ>/`).
  Η AGPLv3 συνδυάζεται με τη GPLv3 του Ruru (GPLv3 §13).

Τα αρχεία των `wood`, `piano` και `nes` είναι αναλλοίωτα.
